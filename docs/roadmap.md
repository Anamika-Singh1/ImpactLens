# Roadmap

## Completed implementation

- Session authentication, workspace Owner/Engineer/Viewer permissions, scoped audit history and database integrity constraints.
- Authorized GitHub snapshot import plus owned fixtures, validation, cancellable bounded jobs and recoverable database outbox.
- Snapshot source explorer, AST dependency graphs, evidence paths and explicit limitations.
- Business feature catalog, human mapping confirmation, suggestions, stale-target review and history.
- Two-tree impact comparisons, saved input/result hashes and explicit review-priority rubric.
- Imported JUnit/Istanbul/LCOV/per-test evidence, explicit feature-test mappings, recommendations and coverage gaps.
- Deterministic explanations and optional consent-gated AI summaries.
- Reviewer decisions, immutable revisions and JSON reports.
- Controlled benchmark with actual five-run measurements; hardening and scoped deletion workflows.
- Production image targets, same-origin routing, migration procedure, CI definitions and isolated synthetic Viewer demo. Local packaging validation is recorded separately in [Phase 11 verification](phase-11-verification.md).

## Future work requiring new implementation or evidence

- Public hosting and a monitored HTTPS deployment, with explicit authorization and operating budget.
- Backup restore rehearsal, measured multi-host failover and production capacity/load evaluation.
- Independently authored, authorized real-world evaluation corpus and larger held-out samples.
- Pull-request selection and merge-base semantics; additional language/framework and dynamic-resolution support.
- Provider-attested CI artifact provenance, richer per-test coverage integrations and test-runner adapters.
- Ownership transfer, account/workspace deletion and configurable audit/source retention.
- Multi-region operation, managed infrastructure templates and deployment automation.

Current gaps are not implemented features. Optional AI requires explicit consent; core review does not depend on it. Fixture metrics are not production ROI.
